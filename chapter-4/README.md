\# Activity 4: Containerization with Docker



\## Goal

Package the application in a reproducible Docker container.



\## Planned Components

\- A `Dockerfile` to define the application image.

\- A `.dockerignore` file to exclude unnecessary files from the build context.

\- A `docker-compose.yml` file to simplify building and running the application.



\## Workflow

1\. Create the Docker configuration files.

2\. Build the Docker image.

3\. Run the container and verify that the application works.



\## Status

Documentation and container configuration are in progress.
